# C++ Basics

Beginner C++ programs I wrote while learning the language, grouped by topic.

| Folder | Programs |
|---|---|
| `basics/` | area, area of a circle, simple interest, sum of natural numbers |
| `Conditional/` | day and month name from a number, max of two and three numbers, positive or negative, simple calculator |
| `loops/` | Armstrong number, digits of a number, factorial, palindrome, reverse a number, multiplication table |
| `Function/` | pass by value, reference and address, function overloading, template functions, linear search |
| `array/` | declaring arrays, for-each, sum and max element, linear and binary search, dynamic arrays |
| `pointers/` | pointer basics, heap allocation |

## Run a program

```bash
g++ loops/factorial.cpp -o factorial
./factorial
```
